Key Features

Real-time Indexing

Continuous blockchain monitoring with configurable confirmation blocks for different reliability requirements.

Reorg Handling

Automatic chain reorganization detection and event reconciliation to ensure data consistency.

GraphQL + REST

Flexible query options with GraphQL for complex queries and REST for simple integrations.

Query Optimization

Smart query routing with Redis caching layer achieving sub-200ms P95 latency.

Rate Limiting

Built-in API key authentication with tiered rate limiting for free and pro users.

Microservices

Clean separation with gRPC communication between Indexer, Query, Admin, and API Gateway services.

Example Query 

query {
  events(
    filter: { eventName: "Transfer" }
    pagination: { first: 10 }
  ) {
    totalCount
    edges {
      node {
        id
        eventName
        blockNumber
        args { key value }
      }
    }
  }
}

REST Endpoints

GET  /api/v1/events                    # List events with filters
GET  /api/v1/events/tx/:txHash          # Events by transaction
GET  /api/v1/events/address/:address    # Events by address
GET  /api/v1/contracts                  # List monitored contracts
POST /api/v1/contracts                  # Add contract to monitor
GET  /api/v1/contracts/:address/stats   # Contract statistics
GET  /api/v1/health                     # Health check
